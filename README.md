# Blogsphere

A modern personal blogging platform built using React and Vite, designed to allow users to create, manage, and share their thoughts efficiently.

---

## Features

* User authentication (login and signup)
* Create, edit, and delete blog posts
* Comment system for user interaction
* Search and filter functionality
* Dark mode interface

---

## Tech Stack

* Frontend: React, Vite
* Styling: CSS / Tailwind CSS
* Version Control: Git and GitHub

---

## Getting Started

### Prerequisites

* Node.js (v18 or higher)
* npm or yarn

---

### Installation

```bash
# Clone the repository
git clone https://github.com/aparnajakka27-sudo/blogsphere.git

# Navigate into the project
cd blogsphere

# Install dependencies
npm install

# Start development server
npm run dev
```

---

### Run Locally

Open your browser and navigate to:
http://localhost:5173
